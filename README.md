### About me

I build data pipelines end to end — from modelling the source system to the dashboard someone actually opens.

Most recently that meant a Python ETL pipeline that turned tens of thousands of templated Word documents spanning 2018–2026 into queryable monthly and yearly datasets, cutting inventory questions from a week of manual cross-checking down to a query. The tools are still in use by non-technical staff after handover.

- 💼 **Open to Data Engineering roles** — Alexandria, remote, or relocation

- 💬 Ask me about dimensional modelling, SCDs, medallion architecture, or anything SQL

### Featured projects

**[Airbnb ELT Pipeline — Snowflake & dbt](https://github.com/mouda4d/airbnb-snowflake-dbt)**
End-to-end ELT on Snowflake with dbt Core: RAW → Bronze → Silver → Gold with incremental loading, SCD Type 2 history through dbt snapshots (working around missing source timestamps), key-pair auth, scoped roles and warehouse cost controls. Every tradeoff is documented in the repo.
`Snowflake` `dbt Core` `SQL`

**[NYC Taxi Lakehouse — Azure ELT Pipeline](https://github.com/mouda4d/Uber-Depi-Grad-Proj)**
DEPI graduation project, led a team of 4. Docker-hosted SQL Server source in 3NF seeded with NYC Taxi + Faker data, ingested to ADLS Gen2 via Data Factory, Bronze/Silver/Gold layers in Databricks with PySpark and Delta Lake, Gold modelled as a star schema feeding a fare-prediction model, served through Synapse serverless SQL into Power BI.
`Azure Data Factory` `Databricks` `Delta Lake` `Synapse` `Airflow` `Power BI`

**[End-to-End Azure Data Engineering Pipeline](https://github.com/mouda4d/End-to-end-Azure-Data-Engineering-Project)**
ADF-orchestrated pipeline over AdventureWorksLT with credentials in Azure Key Vault, bronze→silver→gold transformations in Databricks notebooks, served via Synapse views and Power BI.
`Azure Data Factory` `Key Vault` `Databricks` `Synapse`

**[Multi-Source Data Warehouse Integration](https://github.com/mouda4d/DataWarehouse)**
Merging two SQL Server databases into one warehouse without key collisions — dynamic stored procedures (`sp_executesql`) generate surrogate-key mapping tables, then load integrated data from transformation views into conformed base tables.
`T-SQL` `Azure Data Factory` `Dimensional modelling`
